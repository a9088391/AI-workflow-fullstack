# 驗證紀錄與範圍

本專案以本機展示為驗收目標。以下結果來自專用的 Docker Compose 環境與合成資料。驗收分為框架測試、HTTP／PostgreSQL 契約、瀏覽器操作及查詢效能。

## CQ34 全版本整合驗收

本機提交 `4cf8256` 完成全版本整合驗收與審查。

| 驗證範圍 | 結果 |
| --- | --- |
| 十二後端共同契約 | 兩輪各通過 132 組案例，涵蓋 22 個操作、無效輸入、授權與驗證順序、寫入競爭及跨後端讀回 |
| 前後端互通 | 在同一瀏覽器分頁，十二後端各登入一次，檢查 72 種搭配的受保護頁面及共用文章讀取。切換前端保留原登入期限，切換後端需重新登入 |
| 窄／寬版畫面 | 六版前端的長文詳情共檢查 42 個尺寸點。其他頁面及錯誤狀態由各版既有驗收覆蓋 |
| 重啟與持久化 | 核對正常停止及啟動前後的資料、登入期限、設定和金鑰 |

72 種搭配的驗收限於上述互通流程。實體手機與平板、軟鍵盤及 200% 放大暫緩。跨瀏覽器、系統剪貼簿及瀏覽器返回快取的實際命中未納入本輪驗收。

## PERF01 查詢效能

本機提交 `3577b22` 完成十二後端的列表與搜尋量測及正式審查。使用小量和中量兩組合成資料，各執行兩輪。

- 核對 6,768 個 HTTP 請求窗口的回應、實際 SQL 及查詢次數，其中 192 個為冷機與暖機窗口。
- 比較 1,584 組每頁 1 筆和 20 筆的請求，這些案例的讀取 SQL 次數均未增加。
- 依實際發出的 SQL、綁定值與連線語境補驗 366 份小量及 396 份中量查詢計畫。小量計畫在另一個專用 PostgreSQL 環境用同分布合成資料唯讀重播。

量測工具的最終首次啟動防護以離線替身和 Compose 設定檢查驗證，實際查詢計畫另有 PostgreSQL 執行證據。這些本機樣本不設生產流量或延遲門檻。

測試入口與環境前提見[開發指南](developer-guide.md#從乾淨-checkout-可執行的離線驗收)。服務只供本機展示，未配置 GitHub Actions、公開部署或正式環境維運。
